Changes by Room Studio: OBJ/MTL converted to self-contained GLB; original triangles, normals and texture coordinates retained; parts grouped by material; dimensions set in metres; contemporary white/charcoal/neutral finishes replace wood and colored finishes on selected models. Existing baked appliance and cooktop maps remain embedded. The oven's missing source gradient image is replaced with a PBR metal material. The mirror uses reflective PBR material instead of a baked photograph. The fitted kitchen assembles source modules with a stone finish, actual sink, induction hob, oven front, four base modules and three upper cabinets (one glazed). Source plates and bowls rest on measured shelf tops behind the glass; sink/base worktops meet at the same height. The kitchen has 51,944 original source triangles, grouped into 28 meshes without removing detail. `modern-double-bed.glb` adapts the credited SirOccor / Emmanuel Puybaret `juniorBed` source for a 1.8 m double bed with two separate pillows (23,884 source triangles). Single beds retain the original one-pillow source. PNG previews are our own Three.js renders of the resulting files.

All files are self-hosted. Geometry and decoded textures are shared between repeated instances, and models load only when needed by the visible floor. No source geometry reduction, movement-time detail reduction or runtime model-provider dependency is used. Original notices are retained in [licenses](licenses/). Source attribution is also preserved in this file.

The U-shaped staircase, room shell, glazing, doors, skirting and thin woven rug are procedural architectural/fabric surfaces. Other interior furniture types in the default house use the source models listed above. Old outdoor kinds remain readable in existing version-1 backups but are omitted from the interior preset and furniture picker.
